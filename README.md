## 📝 About the Challenge
Every day, two new problems are released. The goal is to code consistently for 100 days, solve the problems using **C**, and build a strong foundation in problem-solving and logic building.

## 🗂️ Repository Structure
The repository is organized by days. Each folder corresponds to a specific day of the challenge and contains the solutions to the questions released that day. 

Currently covered topics:
* **Day 1 to Day 5**: User Inputs, Operations & Output (Basic Arithmetic, Swapping, Math logic)
* **Day 6**: Conditional Statements (Nested `if-else`, Even/Odd logic)

## 💻 How to Run the Code
You will need a C compiler like `gcc` installed on your machine.

1. Navigate to the directory of the specific day:
   ```bash
   cd "Day 1"
   ```
2. Compile the C file:
   ```bash
   gcc "Q1 (User Inputs, Operations & Output).c" -o Q1
   ```
3. Run the compiled executable:
   ```bash
   # On Windows
   .\Q1.exe
   
   # On Linux/macOS
   ./Q1
   ```
